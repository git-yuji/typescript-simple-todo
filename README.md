# TypeScript Simple Todo

`php-simple-todo`を参考にしたTodoアプリです。

現在の学習範囲は次のとおりです。

- `Task`型の定義
- `Task[]`によるタスク配列
- DOM要素の取得と型指定
- 関数の引数と戻り値の型
- 配列の`map()`を使った画面描画

## 起動方法

```bash
cd typescript-simple-todo
npm run dev
```

ターミナルに表示されたURLをブラウザで開きます。

## ファイル構成

```text
typescript-simple-todo/
├── index.html
├── src/
│   ├── main.ts      タスクのデータと画面描画
│   ├── task.ts      Task型の定義
│   └── style.css    画面のデザイン
└── README.md
```
